Demonstração React da Calendara

Este exemplo precisa do servidor Vite para executar o código React/TypeScript.

Na pasta calendara, execute:

yarn install
yarn dev

Abra o endereço exibido no terminal, normalmente http://127.0.0.1:5173/examples/react.html.

Abrir este arquivo diretamente pelo Explorador de Arquivos não executa o calendário.
